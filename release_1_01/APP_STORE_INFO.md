## 7. App Features

### Core Features
- Practice tracking with customizable goals
- Beautiful lotus and mala progress visualizations
- Smart completion predictions
- Practice history and statistics
- Reminders for daily practice
- Data export (JSON, CSV) and import
- Support for English, Polish, and German

### Counter Features
- Configurable count per tap (+1, +21, +108, custom)
- Optional sounds: click, bell, singing bowl, gong
- Haptic feedback (4 levels)
- Keep screen awake option

### Statistics
- Daily, weekly, monthly averages
- Practice streaks tracking
- Completion date predictions
- Activity charts
